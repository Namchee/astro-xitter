## Theming

Astro Xitter ships with light & dark theme by default and is able to use the appropriate theme based on the following conditions, sorted descending by priority.

- [Media query](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme), specifically `@media (prefers-color-scheme: dark)`
- `[data-theme=light|dark]` attribute on one of its ancestors.

You can also enforce certain theme by passing the `theme` prop to the `Xitter` component, regardless the media query and `data-theme` attribute condition.

```astro
---
import { Xitter } from 'astro-xitter';
---

<Xitter id="20" theme="light" />
```

which will render:

<Container>
    <Xitter id="20" theme="light" />
</Container>
