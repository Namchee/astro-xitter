Astro Xitter is a library that provides components for displaying post embeds from [Twitter / X](https://x.com) similar to what the official [X Publish](https://publish.x.com/) library do.

However unlike using X Publish, all the data fetching and rendering are done in the server-side either statically or on-demand.

This approach eliminates the need to embed an iframe and loading an additional client-side JavaScript as the primary rendering method, therefore reducing network payload and achieving zero [Cumulative Layout Shift (CLS)](https://web.dev/articles/cls) without additional trickery.

This project is inspired by and integrates the idea of [`react-tweet`](https://react-tweet.vercel.app/) library.

## Quick Start

You can start embedding tweets in your Astro site using the `Xitter` component by supplying it with tweet ID in both Astro and MDX files.

<Tabs>
    <TabItem label="Astro">
        ```astro
        ---
        import { Xitter } from 'astro-xitter';
        ---

        <Xitter id="20" />
        ```
    </TabItem>
    <TabItem label="MDX">
        ```mdx
        ---
        title: Title
        description: Description
        ---

        import { Xitter } from 'astro-xitter';

        <Xitter id="20" />
        ```
    </TabItem>
</Tabs>

## Difference With X Publish

While this library aims to replicate the visual appearance and capability of the official [X Publish](https://publish.x.com/) library, there are a few differences between tweets rendered by Astro Xitter and the official implementation:

### User Experience

- The main tweet container is no longer hoverable and cannot be used to navigate directly to the tweet.

### Styling

- **Color Tokens**: While the base color tokens are accurate, state modifiers (such as pseudo-classes and pseudo-elements) may differ slightly. However, they remain closely matched.
- **Text Color**: The tweet text color is slightly more subdued than the original X Publish implementation, which uses pure black or pure white.
- **Spacing**: Spacing between certain elements has been increased—notably between the user avatar and profile details, as well as between profile details and tweet text in reply contexts.
- **Video Controls**: Video player controls rely on native browser styling rather than mimicking the custom appearance of X Publish's video player.
